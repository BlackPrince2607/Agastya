# Phone screenshots for Google Play

Play requires **at least 2** phone screenshots (recommend 5–7).

## Capture

1. Build a release/preview APK or use a device with the production-like UI.
2. Use a recent phone resolution (e.g. 1080×2400). Avoid status-bar secrets.
3. Save PNGs here with these names:

| File | Screen |
|------|--------|
| `01-palm-scan.png` | Palm scan camera |
| `02-analysis.png` | Analysis / seal |
| `03-report.png` | Full report overview |
| `04-chat.png` | AI Guide chat |
| `05-tasks.png` | Daily tasks |
| `06-compatibility.png` | Compatibility |
| `07-paywall.png` | One-time Premium paywall |

4. Upload the same set in Play Console → Store listing → Phone screenshots.
